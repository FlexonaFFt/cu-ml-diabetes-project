## О проекте

Учебный ML-проект о повторной госпитализации пациентов с диабетом. Хотим предсказать к моменту выписки, вернётся ли пациент в стационар раньше чем через 30 дней. Сравним логистическую регрессию с более сложными моделями, а случайное разбиение с разбиением по пациентам. Проверим вклад признаков и обработки аномалий, попробуем прогноз на три класса и разберём предсказания с помощью SHAP. Отдельно исследуем, можно ли выделить группы больниц по доступным признакам. Работаем с [данными UCI](https://doi.org/10.24432/C5230J).
